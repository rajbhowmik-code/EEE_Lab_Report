## 🛠️ Building the Reports

**Requirements:** a LaTeX distribution such as [TeX Live](https://www.tug.org/texlive/), [MiKTeX](https://miktex.org/), or an online editor like [Overleaf](https://www.overleaf.com/).

```bash
# Compile a single report
cd reports/experiment-01
pdflatex report.tex
pdflatex report.tex   # run twice to resolve references
```

## 📝 Report Structure

Each report generally follows this format:

1. Experiment Title & Objective
2. Apparatus / Components Required
3. Theory
4. Circuit Diagram
5. Procedure
6. Data & Observations
7. Calculations
8. Results & Discussion
9. Conclusion
